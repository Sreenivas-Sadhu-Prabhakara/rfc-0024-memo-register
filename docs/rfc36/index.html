RFC 36 · Handshake readiness

Educational establishment model: A sends, B receives. Each endpoint becomes locally ready after issuing its own request, receiving the peer request, and observing acknowledgment of its own request.

request = local initiation; receive_request = handling the peer request; ack = handling RFNM for the local request. try_send probes A's establishment readiness only. It does not transmit data or model flow-control permission.
